# Práctica 00. Iniciación a JavaScript

## Objetivos

En esta práctica he preparado el repositorio del módulo y he tenido una primera toma de contacto con JavaScript.

## Ejercicio 1. Mi primer programa

Es un programa donde aprendemos a usar las variables para crear nuestro primer Pokémon. Primero muestra unos mensajes con console.log, después creo las variables del nombre, tipo y nivel (yo puse a Celebi) y al final las muestro juntas en una frase.

## Ejercicio 2. Operaciones básicas

Es un programa donde además de utilizar las variables también hacemos una operación, que es sumar la experiencia actual y la ganada para sacar la total de mi Pokémon. Después con un if se comprueba si la total llega a 100 y dependiendo de eso sale un mensaje u otro (puede subir de nivel o todavía no).

## Conceptos utilizados

- `console.log()`: Sirve para mostrar en la terminal lo que deseamos.
- Variable: Es algo que creamos con const, lo cual permite almacenar texto, números, sin necesidad de especificar qué tipo es al momento de crearla.
- Texto: Por ejemplo el nombre del Pokémon, va entre comillas.
- Número: Por ejemplo el nivel del Pokémon, va sin comillas. Si le pones comillas lo trata como texto y en vez de sumar te lo pega (70 + 30 sale 7030).
- Condición: Usamos if en este caso, si se cumple la condición (experiencia total >= 100) sale un mensaje y si no sale otro.

## Dificultades encontradas

Al venir de Java mayormente es un poco raro el uso del $ por ejemplo para llamar a las variables dentro de las llaves, y visualmente es un poco diferente a Java. También me costó escribir el acento grave con el teclado, lo solucioné pulsando la tecla y después espacio. Pero creo que por ahora estamos a un buen nivel empezando.
